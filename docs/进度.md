## 3. 详细开发记录

### 基建
- ✅ **建表**：`db/schema.sql` 建 `user_profile / training_log / body_metric / doc_chunk`，含 pgvector HNSW 向量索引；云服务器 docker 一键 `scripts/init-db.sh` 执行。
- ✅ **接入**：后端加 spring-data-r2dbc + r2dbc-postgresql，连接走环境变量；Docker 多阶段构建（阿里云 Maven 镜像解决 central 不通）；端口 8081（避开占用的 8080）。

### F-01 训练日志 CRUD
- 四层：`TrainingLog` 实体 / Repository / Service / Controller。
- **验收**：POST/GET/PUT/DELETE 全跑通。已合并 main。

### F-02 身体指标
- 三接口：POST（同天字段级覆盖合并）/ 范围查询(升序) / latest。
- **验收**：覆盖合并实测通过（只传体重、腰围保留）。已合并 main。

### F-03 RAG · 入库管线
- `DocumentChunker`（中文分块，按段落边界 + maxChars 兜底）
- `EmbeddingClient`（WebClient 手写调阿里云百炼 `/embeddings`，1024 维）
- `IngestService`（分块→embed→原生 SQL `:embedding::vector` 写入 doc_chunk，绕开 r2dbc 不支持 vector 的问题）
- `IngestController`（POST /api/ingest）
- **验收**：POST /api/ingest 写入 1 块，`vector_dims(embedding)=1024`。

### F-03 RAG · 混合检索（第 6 步）
- `LuceneIndexService`（BM25 倒排索引，ByteBuffersDirectory + StandardAnalyzer，懒加载+invalidate）
- `VectorSearchService`（pgvector 余弦相似度 `1-(<=>)`）
- `SearchService`（RRF 融合，两路按 (docId,chunkIndex) 累加 1/(k+rank)）
- `SearchController`（GET /api/search?q=&top=）
- **验收**：审查+联测通过，接口返回正确 chunk，RRF 两路命中分=2/61。

### F-03 RAG · 问答生成带引用（第 7 步 · 完成）
- `ChatClient`（WebClient 调百炼 `/chat/completions`，`qwen3.8-flash`）
- `ChatService`（检索 top-5 → 拼 prompt(安全边界：只依据知识/不编造) → 生成 → 映射 sources；双降级：空检索拒答 / LLM 异常兜底）
- `ChatController`（POST /api/chat）+ `ChatResponse`/`SourceHit`
- **验收**：验收1(知识内→基于知识+标注[1]+sources[d1])、验收2(超出范围→“根据现有知识无法确定”)均通过。
- ✅ **RAG 三环全部闭环，`feature/rag` 已合并回 main**（`8ddcca1`）。F-03 完成。

## 5. 技术备忘（踩过的坑 / 关键约束）

- **Maven central 国内服务器不通** → 用阿里云镜像 `maven-settings.xml`。
- **8080 被服务器另一服务占用** → SelfCoach 后端走 **8081**（docker-compose 已配）。
- **r2dbc-postgresql 默认不支持 vector 列** → 用 DatabaseClient 原生 SQL + `:embedding::vector` 写入。
- **Embedding 维度必须 = vector(1024)**：用 `qwen3.7-text-embedding-flash` 的 `dimensions:1024`，已实测匹配。
- **Lucene QueryParser 需单独依赖**：`queryparser` 不在 `lucene-core`，要加 `lucene-queryparser`，否则检索代码报 `package org.apache.lucene.queryparser.classic does not exist`（第 6 步踩到并已修）。
- 中文 BM25 目前用 StandardAnalyzer 是单字分词，专名/罕见词较依赖向量路补盲；演进可换 smartcn / ik 分词。
- 云服务器后端验证：`docker compose up -d --build backend`；数据库密码等敏感信息走 `.env`，不进库不进 git。
