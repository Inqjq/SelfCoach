## 2. 目录结构（前后端分离）

```
SelfCoach/
├── backend/                 # Spring Boot 3 + WebFlux 后端（只出 REST + SSE API）
│   ├── pom.xml
│   └── src/
│       ├── main/java/com/selfcoach/
│       │   ├── SelfCoachApplication.java   # 启动类
│       │   └── api/HealthController.java   # 健康检查（基础设施）
│       ├── main/resources/application.yml
│       └── test/java/com/selfcoach/
├── frontend/                # Vue 3 + Vite 前端（独立工程，联调走 /api 代理）
│   ├── package.json
│   ├── vite.config.js
│   ├── index.html
│   └── src/{main.js, App.vue}
├── docs/                    # 需求 / 技术 / 开发计划 / 进度
├── docker-compose.yml       # PostgreSQL 16 + pgvector
├── README.md
└── agent.md
```

**前后端职责边界**
- 后端：只负责业务与数据，通过 `REST + SSE` 暴露 JSON / 流式接口，不做页面渲染。
- 前端：负责交互与展示，调用后端 API；对话用 SSE 流式接收。
- 联调：前端 dev 服务器把 `/api` 代理到 `http://localhost:8080`。
